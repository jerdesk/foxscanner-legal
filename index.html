Questions fréquentes

Où sont stockés mes documents ?

Uniquement sur votre appareil. FoxScanner n'a aucun serveur : personne d'autre que vous n'a accès à vos documents. Si vous activez la sauvegarde cloud, elle part vers votre compte Google Drive ou iCloud.

Comment activer la sauvegarde cloud ?

Réglages → « Sauvegarder automatiquement sur… », puis choisissez Google Drive ou iCloud (iPhone). La sauvegarde manuelle est aussi disponible dans la même section.

Comment restaurer mon achat Premium ?

Réglages → section Premium → « Restaurer mes achats », avec le même compte App Store / Google Play que lors de l'achat.

Le cadre de détection ne trouve pas mon document, que faire ?

Posez le document sur un fond contrasté et évitez les reflets directs. Dans tous les cas, vous pouvez ajuster les coins à la main sur l'écran de cadrage après la prise de vue, ou importer une photo depuis la galerie.

Comment supprimer toutes mes données ?

Désinstaller l'application supprime toutes les données locales. Les sauvegardes cloud éventuelles se suppriment depuis l'application ou depuis votre compte Google Drive / iCloud.
